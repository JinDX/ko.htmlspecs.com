1. 소개

이 명세는 지정된 범위에서 포인터 위치가 이동한 정도에 따라 애니메이션의 진행을 구동하는 메커니즘을 정의한다. 이런 포인터 구동 애니메이션 은 포인터 위치에 따른 타임라인을 사용하며, 시간이 아니라 길이를 기준으로 한다. 이와 같은 방식은 다음 애니메이션과 동작이 비슷하고 개념도 공유한다: 스크롤 구동 애니메이션. 이 모듈은 Web Animations API를 기반으로 하는 명령형 API와 CSS 애니메이션을 기반으로 하는 선언형 API를 모두 제공한다. [CSS-ANIMATIONS-2] [WEB-ANIMATIONS-1]

1.1. 다른 명세와의 관계

Web Animations [WEB-ANIMATIONS-1] 는 웹 플랫폼 애니메이션의 추상적 개념 모델을 정의한다. 이 모델의 구성 요소에는 애니메이션 과 그 타임라인, 그리고 관련 프로그래밍 인터페이스가 있다. 이 명세는 새 타임라인을 정의한다. 바로 포인터 진행 타임라인 이며, 이를 사용하여 애니메이션 의 진행을 구동하고 포인터 구동 애니메이션을 만들 수 있다. 이로써 Web Animations 모델을 확장한다.

이 명세는 두 가지를 도입한다. 하나는 이러한 개념을 다루기 위한 프로그래밍 인터페이스이며, 다른 하나는 이러한 개념을 CSS 애니메이션 [CSS-ANIMATIONS-1]에 적용하는 CSS 속성이다. 이러한 CSS 속성의 동작이 프로그래밍 인터페이스를 통해 설명되어 있더라도, 스크립트를 지원하지 않는 사용자 에이전트 는 기반 프로그래밍 인터페이스가 있는 것처럼 CSS 기능이 동작하도록 구현하면 이 명세를 준수할 수 있다.

이 명세는 진행률 기반 타임라인과 애니메이션을 지정하기 위해 스크롤 구동 애니메이션 모듈 [SCROLL-ANIMATIONS-1] 이 도입한 개념과 기능에서 영감을 받아 파생되었다.

CSS에서 선택자 매칭을 제외한 대부분의 연산과 마찬가지로, 이 명세의 기능도 다음을 대상으로 동작한다: 평탄화된 요소 트리.

1.2. 값 정의

이 명세는 다음 CSS 속성 정의 규칙 을 따른다( [CSS2] 참조). 또한 다음 값 정의 구문 을 사용한다( [CSS-VALUES-3]참조). 이 명세에서 정의하지 않은 값 유형은 CSS Values & Units [CSS-VALUES-3]에 정의되어 있다. 다른 CSS 모듈과 함께 사용하면 이러한 값 유형의 정의가 확장될 수 있다.

이 명세에 정의된 모든 속성은 각 정의에 나열된 속성별 값 외에도 속성값으로 CSS 전역 키워드 를 허용한다. 읽기 쉽게 하기 위해 각 정의에서 이를 반복하여 명시하지 않는다.

2. 포인터 진행 타임라인

포인터 진행 타임라인 은 특정 축을 따라 요소의 주 상자 위에서 포인터의 위치가 이동한 정도에 연동되는 타임라인이다.

포인터 범위 는 다음 크기를 말한다: 요소의 주 상자 를 포인터 진행 타임라인의 축을 따라 잰 크기.

포인터 오프셋 은 포인터의 위치를 요소의 포인터 범위의 시작에 상대적으로 나타낸 값이며, 다음 정의를 따른다: offsetX 및 offsetY ( [CSSOM-VIEW-1]). 시작 쪽 끝의 포인터 오프셋 은 0% 진행률을 나타내고 끝 쪽 끝의 포인터 오프셋 은 100% 진행률을 나타낸다.

포인터 진행 타임라인 은 animation-timeline 에서 pointer() 함수 표기법을 사용하여 익명으로 참조하거나, 이름으로 참조할 수 있다( 스크롤 구동 애니메이션 § 4.2 이름이 있는 타임라인의 범위 지정과 조회참고). 이름으로 참조하려면 먼저 pointer-timeline 속성으로 선언한다. Web Animations API에서는 PointerTimeline 객체로 익명 타임라인을 나타낼 수 있다.

2.1. 포인터 진행 타임라인 범위

포인터 진행 타임라인 은 다음과 같은 이름이 있는 타임라인 범위를 정의한다:

fill
다음과 같이 포인터 진행 타임라인의 전체 범위를 나타낸다:

  • 0% 진행률은 포인터가 요소의 시작 패딩 가장자리 (기준 상자: 주 상자)에 놓인 위치를 나타낸다.

  • 100% 진행률은 포인터가 요소의 끝 패딩 가장자리 (기준 상자: 주 상자)에 놓인 위치를 나타낸다.

fit
fill과 크기가 같은 범위를 나타내되, 0%와 100% 진행률 지점은 animation-range-center 속성값에 따라 이동하므로 50% 진행률 지점은 범위의 중심에 유지된다.
cover
다음과 같이 포인터 진행 타임라인 에서 요소의 주 상자 를 완전히 덮는 가장 큰 범위를 나타낸다. 이 범위는 animation-range-center 속성값에 따른다:

  • 50% 진행률 지점에서 요소의 시작 패딩 가장자리 까지의 거리가 50% 진행률 지점에서 요소의 끝 패딩 가장자리까지의 거리보다 크면, 0% 진행률 지점은 요소의 시작 패딩 가장자리에 있고, 100% 진행률 지점은 50% 진행률 지점에서 같은 거리만큼 떨어진 반대쪽에 있다.

  • 그렇지 않으면 100% 진행률 지점은 요소의 끝 패딩 가장자리에 있고, 0% 진행률 지점은 50% 진행률 지점에서 같은 거리만큼 떨어진 반대쪽에 있다.

contain
다음과 같이 요소의 주 상자 에 완전히 포함되는 가장 큰 범위를 나타낸다. 이 범위는 animation-range-center 속성값에 따른다:

  • 50% 진행률 지점에서 요소의 시작 패딩 가장자리 까지의 거리가 50% 진행률 지점에서 요소의 끝 패딩 가장자리까지의 거리보다 작으면, 0% 진행률 지점은 요소의 시작 패딩 가장자리에 있고, 100% 진행률 지점은 50% 진행률 지점에서 같은 거리만큼 떨어진 반대쪽에 있다.

  • 그렇지 않으면 100% 진행률 지점은 요소의 끝 패딩 가장자리에 있고, 0% 진행률 지점은 50% 진행률 지점에서 같은 거리만큼 떨어진 반대쪽에 있다.

도식을 삽입한다.

모든 경우에 쓰기 모드 는 시작 과 끝 쪽을 결정하는 데 사용되며, 해당 쓰기 모드 는 관련 주 상자의 것을 사용한다. 변환 은 무시하지만 상대 및 절대 위치 지정은 고려한다.

2.2. 포인터 진행 타임라인의 진행률 계산

진행률( 현재 시간)은 각 포인터 진행 타임라인 에 대해 다음과 같이 계산한다: 포인터 오프셋 ÷ 포인터 범위

0% 위치와 100% 위치가 일치하면 (즉, 현재 시간 공식의 분모가 0이면), 타임라인은 비활성이다.

2.3. 익명 포인터 진행 타임라인

2.3.1. pointer() 표기법

pointer() 함수 표기법은 <single-animation-timeline> 값을 animation-timeline 에서 지정하는 데 사용할 수 있으며 포인터 진행 타임라인을 지정한다. 구문은 다음과 같다.

<pointer()> = pointer( [ <source> || <axis> ]? )
<axis> = block | inline | x | y
<source> = root | nearest | self

기본적으로 pointer() 는 인라인 축 을 참조한다. 기준은 요소 자체의 포인터 범위다. 인수는 이 조회를 다음과 같이 바꾼다:

block
다음 축을 따라 측정한 진행률을 사용한다: 블록 축 (기준 범위: 포인터 범위).
inline
다음 축을 따라 측정한 진행률을 사용한다: 인라인 축 (기준 범위: 포인터 범위). (기본값.)
x
다음 축을 따라 측정한 진행률을 사용한다: 가로 축 (기준 범위: 포인터 범위).
y
다음 축을 따라 측정한 진행률을 사용한다: 세로 축 (기준 범위: 포인터 범위).
self
요소 자체의 주 상자 를 포인터 범위로 사용하도록 지정한다. (기본값.)
nearest
가장 가까운 요소의 부모 상자 를 포인터 범위로 사용하도록 지정한다.
root
루트 요소의 주 상자 를 포인터 범위로 사용하도록 지정한다.

pointer() 를 사용할 때마다 각자 별개의 PointerTimeline 인스턴스에 대응한다(Web Animations API). 여러 요소가 pointer() 에 같은 인수를 넘겨 같은 포인터 범위 를 참조하더라도 마찬가지다.

2.3.2. PointerTimeline 인터페이스

enum PointerAxis {
  "block",
  "inline",
  "x",
  "y"
};

dictionary PointerTimelineOptions {
  Element? source;
  PointerAxis axis = "block";
};

[Exposed=Window]
interface PointerTimeline : AnimationTimeline {
  constructor(optional PointerTimelineOptions options = {});
  readonly attribute Element? source;
  readonly attribute PointerAxis axis;
};

PointerTimeline 은 AnimationTimeline 으로서 포인터 진행 타임라인을 나타낸다. 다음에 전달할 수 있다: Animation 생성자 또는 animate() 메서드. 그러면 애니메이션을 포인터 진행 타임라인에 연결할 수 있다.

source, 유형은 Element, 읽기 전용, null 허용

포인터 오프셋 으로 타임라인의 진행을 구동하는 요소다.

axis, 유형은 PointerAxis, 읽기 전용

타임라인의 진행을 구동하는 축이다. 위의 <axis>에 해당하는 값 정의를 참조하라.

상속된 특성:

currentTime ( AnimationTimeline에서 상속)

2.4. 이름이 있는 포인터 진행 타임라인

포인터 진행 타임라인 은 선언적으로도 정의할 수 있고, 이후 그 이름의 범위에 속한 요소에서 이름으로 참조할 수 있다. ( 스크롤 구동 애니메이션 § 4.2 이름이 있는 타임라인의 범위 지정과 조회참고.)

이러한 이름이 있는 포인터 진행 타임라인 은 조정된 값 목록 ( pointer-timeline-* 속성으로 구성됨)에서 선언한다. 이 속성들은 조정 목록 속성 그룹 을 이루며, pointer-timeline-name 이 조정 목록 기본 속성이다. CSS Values 4 § A 조정 목록 값 속성을 참조하라.

부록 A: 애니메이션 범위의 중심 설정

이 절은 CSS-ANIMATIONS-2 및 WEB-ANIMATIONS-2로 옮겨야 한다.

스크롤 구동 애니메이션 §  애니메이션을 타임라인 범위에 연결하기 절에서는 애니메이션 키프레임 집합을 애니메이션 연결 범위에 연결하는 개념을 소개한다. 이를 통해 애니메이션에 단일 선형 진행 범위를 만든다.

포인터 구동 애니메이션에서는 새롭게 애니메이션의 초점, 즉 50% 진행률 지점을 특정 위치로 지정할 수 있다. 이 지점은 기본적으로 애니메이션 연결 범위의 중심이지만, animation-range-center 속성으로 바꿀 수 있다.

애니메이션 범위 중심의 기준 요소 란 그 주 상자 의 범위를 기준으로 활성 범위의 중심을 계산하는 요소를 말한다. <timeline-range-center-subject> 값 유형으로 나타내며, 이 유형은 CSS 식별자 로 다음 중 하나를 나타낸다:

source
포인터 오프셋 으로 타임라인의 진행을 구동하는 요소.
target
애니메이션이 적용되는 요소.

50% 진행률 지점이 0% 진행률 지점보다 작거나 100% 진행률 지점보다 클 수 있다. 이 경우 애니메이션 연결 범위 는 50% 진행률 지점에서 잘린다.

애니메이션 타임라인 범위의 중심 지정: animation-range-center 속성

이름: animation-range-center
값: [ normal | [ <length-percentage> | <timeline-range-center-subject> <length-percentage>? ] ]#
초깃값: normal
적용 대상: 모든 요소
상속: 아니요
백분율: 지정한 타임라인 범위 중심의 기준 요소에서 해당하는 치수를 기준으로 한다. 기준 요소가 지정되지 않은 경우 다음 범위의 시작점을 기준으로 한다: 애니메이션 연결 범위
계산값: 목록. 각 항목은 키워드 normal 또는 타임라인 범위 중심의 기준 요소와 길이-백분율 값의 쌍이다.
정규 순서: 문법에 따름
애니메이션 유형: 애니메이션 불가

애니메이션 연결 범위의 중심점을 지정한다. 즉 애니메이션 범위에서 50% 진행률 지점이 어디인지 지정한다.

각 값의 의미는 다음과 같다:

normal
애니메이션의 활성 구간 에서 50% 진행률 지점은 애니메이션 연결 범위의 중심에 있다.
<length-percentage>
애니메이션의 활성 구간 에서 50% 진행률 지점은 타임라인 에서 애니메이션 연결 범위의 시작점을 기준으로 지정한 지점에 있다. 백분율은 애니메이션 연결 범위의 크기를 기준으로 한다.
<timeline-range-name> <length-percentage>?
애니메이션의 활성 구간 에서 50% 진행률 지점은 시작 패딩 가장자리 를 기준으로 지정한 위치에 있다. 그 가장자리는 지정한 애니메이션 범위 중심의 기준 요소의 주 상자에 속한다. <length-percentage> 를 생략하면 기본값은 50%다.

테스트

이 명세의 내용과 관련된 테스트는 이와 같은 “테스트” 블록에 기록할 수 있다. 이러한 블록은 모두 비규범적이다.

    적합성 클래스

    이 명세의 적합성은 세 가지 적합성 클래스에 대해 정의된다:

    스타일 시트
    CSS 스타일 시트.
    렌더러
    사용자 에이전트 로서 스타일 시트의 의미를 해석하고 그 스타일 시트를 사용하는 문서를 렌더링한다.
    저작 도구
    사용자 에이전트 로서 스타일 시트를 작성한다.

    스타일 시트가 이 명세에 적합하려면 이 모듈에서 정의한 구문을 사용하는 모든 문이 일반 CSS 문법과 이 모듈에 정의된 각 기능의 개별 문법에 따라 유효해야 한다.

    렌더러가 이 명세에 적합하려면 해당 명세에 정의된 대로 스타일 시트를 해석하는 것에 더해 이 명세에 정의된 모든 기능을 지원해야 한다. 즉 각 기능을 올바르게 파싱하고 이에 맞게 문서를 렌더링해야 한다. 다만 장치의 제약으로 사용자 에이전트가 문서를 올바르게 렌더링하지 못한다고 해서 이 사용자 에이전트가 명세에 부적합한 것은 아니다. (예를 들어 흑백 모니터에서 색을 렌더링할 필요는 없다.)

    저작 도구가 이 명세에 적합하려면 작성하는 스타일 시트의 구문이 일반 CSS 문법과 이 모듈에 있는 각 기능의 개별 문법에 맞아야 하며, 스타일 시트에 대해 이 모듈에 명시된 다른 모든 적합성 요구 사항도 충족해야 한다.

    부분 구현

    작성자가 순방향 호환 파싱 규칙으로 대체 값을 지정할 수 있도록, CSS 렌더러는 지원하지 않는 구문을 유효하지 않은 것으로 처리해야 한다 (적절한 경우 무시해야 한다). 여기에는 실용적인 수준으로 지원하지 않는 앳 규칙, 속성, 속성값, 키워드 및 그 밖의 구문 요소가 포함된다. 특히 사용자 에이전트는 다음과 같이 처리해서는 안 된다 : 여러 값을 포함한 하나의 속성 선언에서 지원하지 않는 구성 요소 값만 골라서 무시하고 지원하는 값만 적용하는 것. 어떤 값이든 유효하지 않은 것으로 간주되는 경우 (지원하지 않는 값은 반드시 그렇게 간주한다), CSS는 선언 전체를 무시하도록 요구한다.

  "x",
  "y"

  Element? source;
  PointerAxis axis = "block";
