1. 소개

이 명세는 애니메이션 재생에 영향을 주는 메커니즘을 정의한다. 이는 지정된 트리거를 호출하는 다양한 사용자 상호작용을 바탕으로 한다. 애니메이션에 트리거를 지정하면 해당 애니메이션은 트리거 애니메이션이 되며, 그 트리거가 발생할 때까지 재생 시작이 지연된다. 이 트리거는 특정 Event([DOM]에 정의됨)에 연결되거나, 뷰 진행 타임라인과 같은 타임라인을 기반으로 할 수 있다. [SCROLL-ANIMATIONS-1]

이 모듈은 Web Animations API를 바탕으로 하는 명령형 API와 CSS Animations를 바탕으로 하는 선언형 API를 모두 제공한다. [CSS-ANIMATIONS-2] [WEB-ANIMATIONS-1]

1.1. 다른 명세와의 관계

Web Animations [WEB-ANIMATIONS-1]은 Web 플랫폼의 애니메이션에 대한 추상적 개념 모델을 정의한다. 모델의 요소에는 애니메이션과 타임라인이 포함되며, 관련 프로그래밍 인터페이스도 정의한다. 이 명세는 Web Animations 모델을 확장하여 트리거 애니메이션을 정의하고, 트리거를 통해 이러한 애니메이션에 재생 제어 기능을 수행할 수 있게 한다.

이 명세는 이러한 개념과 상호작용하기 위한 프로그래밍 인터페이스와, 이 개념을 CSS Animations에 적용하는 CSS 속성을 모두 도입한다. [CSS-ANIMATIONS-2] 이러한 CSS 속성의 동작을 프로그래밍 인터페이스를 통해 설명하더라도, 스크립트를 지원하지 않는 사용자 에이전트는 이 명세를 준수할 수 있다. 이를 위해서는 기반 프로그래밍 인터페이스가 존재하는 것처럼 CSS 기능이 동작하도록 구현하면 된다.

이 명세는 Scroll-Driven Animations 모듈 [SCROLL-ANIMATIONS-1]이 도입한 타임라인 및 범위 개념을 사용하여 진행도 기반 타임라인과 애니메이션을 규정한다.

선택자 일치를 제외한 대부분의 CSS 작업과 마찬가지로, 이 명세의 기능은 평탄화된 요소 트리에서 동작한다.

1.2. 값 정의

이 명세는 CSS 속성 정의 규칙 （[CSS2]）을 따르고, 값 정의 구문 （[CSS-VALUES-3]）을 사용한다. 이 명세에서 정의하지 않은 값 타입은 CSS Values & Units [CSS-VALUES-3]에서 정의한다. 다른 CSS 모듈과 결합하면 이러한 값 타입의 정의가 확장될 수 있다.

각 속성의 정의에 나열된 고유한 값 외에도, 이 명세에서 정의하는 모든 속성은 CSS 전역 키워드를 속성 값으로 허용한다. 가독성을 위해 이를 명시적으로 반복하지 않는다.

2. 트리거

트리거는 한 요소에서의 사용자 상호작용을 다른 요소(또는 같은 요소)에 지정된 동작을 적용하는 것과 연결한다.

현재 두 종류의 트리거가 정의되어 있다:

  • 타임라인 트리거는 timeline-trigger 속성으로 관리되며, 특정 타임라인 범위에 진입하거나 이탈할 때 동작을 트리거할 수 있다. (보통 뷰 진행 타임라인을 사용하므로, 예를 들어 요소가 화면에 들어올 때 애니메이션을 시작할 수 있다.)

  • 이벤트 트리거는 event-trigger 속성으로 관리되며, 요소 클릭이나 특정 키 누르기와 같은 사용자 상호작용 이벤트로 동작을 트리거할 수 있다.

트리거는 특정 트리거 요소에 정의된다. 모든 트리거에는 트리거 이름이 있으며, 구체적인 트리거 종류가 활성화 방식과 시점을 결정한다.

트리거가 정의되면 해당 종류의 트리거 인스턴스가 trigger-scope 속성에서 관리하는 범위 안에 생성된다. 지정된 각 트리거 요소마다 트리거 연결이 일치하는 인스턴스에 생성된다. 이 인스턴스의 이름 및 trigger-scope는 일치해야 한다.

트리거 연결의 구체적인 "종류"가 관련 인스턴스의 "그룹화"를 결정한다. 즉, 이벤트 트리거 연결은 이름과 범위가 같으면 하나의 인스턴스로 묶인다. 마찬가지로 타임라인 트리거는 별도로 그룹화된다. 그러나 같은 범위 안에서 다른 종류의 트리거 이름을 정의하면 이전에 정의된 트리거 이름을 덮어쓴다.

트리거는 임의의 요소에서 사용될 수 있다. 이를 통해 해당 요소에서 트리거 인스턴스와의 연관 관계를 만든다. 그 인스턴스는 같은 이름을 가진다. (예를 들어 animation-trigger는 트리거 인스턴스를 요소의 특정 애니메이션과 연결한다.) 트리거를 사용하는 요소는 연관된 트리거가 활성화되거나 비활성화될 때 수행할 동작을 지정한다.

참고: 트리거와 트리거 인스턴스의 설계 및 이를 트리거 애니메이션과 <animation-action>에 연결하는 방식은 의도적으로 어느 정도 범용성을 갖도록 설계되었다. 이는 향후 트리거를 다른 목적으로 사용하는 것을 지원하기 위함이다. 다만 현재 이 기능은 트리거 애니메이션에서만 사용한다.

2.1. 트리거 동작

트리거를 요소의 트리거로 사용할 때는 하나 또는 두 개의 동작을 연결할 수 있다 （예: animation-trigger 사용）. 두 개를 지정하면 첫 번째는 트리거의 진입 동작이며, 트리거가 활성화될 때 적용하는 동작이다. 두 번째는 트리거의 이탈 동작이며, 트리거가 비활성화될 때 적용하는 동작이다.

2.2. 트리거 내부 상태

트리거 인스턴스 trigger는 내부 불리언 트리거됨 플래그를 가지며, 초깃값은 false이다. 또한 내부 상태를 가지며, 가능한 값은 다음과 같다:

대기
초기 상태 . 트리거 의 트리거됨 플래그가 false인 동안의 상태이다.
활성
이 값으로 전환되면 트리거 는 지정된 다음 동작을 적용한다: 진입 동작.
비활성
이 값으로 전환되면 트리거 는 지정된 다음 동작을 적용한다: 이탈 동작.

2.3. 트리거 이름의 범위: trigger-scope 속성

트리거 이름은 기본적으로 전역이며, 다른 요소는 위치에 관계없이 사용할 수 있다. (다만 이는 트리 범위 이름이므로, 섀도 루트와 상호작용한다.) 여러 요소가 트리거를 같은 트리거 이름으로 선언하면, 이들은 별개의 연결로 묶여 같은 트리거 인스턴스에 속한다. 이 인스턴스의 트리거 이름과 종류는 같다.

trigger-scope 속성은 이름의 범위를 문서의 하위 트리로 제한할 수 있다. 그러면 외부 요소에서는 선택된 트리거 이름이 보이지 않고, 내부 요소에서는 트리거 이름 중 해당 범위 안에서 정의된 것만 보인다.

이름: trigger-scope
값: none | all | <dashed-ident>#
초기값: none
적용 대상: 모든 요소
상속: 아니요
백분율: 해당 없음
계산값: 지정된 대로
정규 순서: 문법에 따름
애니메이션 유형: 애니메이션 불가

이 속성은 트리거 이름의 범위를 일치하는 요소의 하위 트리로 제한한다. 값은 다음과 같다:

none
변경하지 않는 대상은 트리거 이름 범위이다.
all
다음의 모든 트리거 이름 (이 요소 또는 그 자손이 정의하고, 자손이 다음을 사용하여 아직 범위를 제한하지 않은 것): trigger-scope)에 대해 범위에 포함되는 대상을 이 요소의 평탄 트리 자손으로 제한한다. 또한 자손이 다음을 일치시킬 수 있는 대상을 제한한다: 트리거 이름 의 일치 대상은 트리거 중 이 하위 트리 안에 있는 것뿐이다.

이 값은 같은 트리 범위의 트리거 이름에만 영향을 주며, 엄격하게 일치하는 트리 범위 이름처럼 동작한다. (즉, trigger-scope: all은 trigger-scope: --foo, --bar, ...로 관련된 모든 트리거 이름을 나열한 경우와 동일하게 동작한다.)

<dashed-ident>
일치하는 트리거 이름 (이 요소 또는 그 자손이 정의하고, 자손이 다음을 사용하여 아직 범위를 제한하지 않은 것): trigger-scope)에 대해 범위에 포함되는 대상을 이 요소의 평탄 트리 자손으로 제한한다. 또한 자손이 이들을 일치시킬 수 있는 대상을 제한한다: 트리거 이름 의 일치 대상은 트리거 중 이 하위 트리 안에 있는 것뿐이다.

<dashed-ident>는 엄격하게 일치하는 트리 범위 이름을 나타낸다. 즉, 같은 섀도 트리의 트리거 이름에만 일치할 수 있다. [CSS-SCOPING-1]

3. 타임라인 트리거

타임라인 트리거는 트리거의 한 종류로, 어떤 타임라인이 트리거의 활성화 범위에 들어오면 활성화되고, 활성 범위에서 벗어나면 비활성화된다. 요소에서 timeline-trigger 단축 속성 또는 그 개별 속성으로 정의한다. 요소에 정의되면 연결을 형성하여 트리거 인스턴스에 연결된다. 그 인스턴스는 지정된 이름과 범위를 가진다.

요소는 여러 타임라인 트리거를 정의할 수 있으며, 같은 타임라인(범위는 다를 수 있음) 또는 서로 다른 타임라인을 사용할 수 있다. timeline-trigger 개별 속성 집합은 조정 목록 속성 그룹을 구성한다. timeline-trigger-name이 조정 목록 기준 속성이며, 조정된 값 목록의 각 항목이 하나의 타임라인 트리거의 속성을 정의한다.

3.1. 타임라인 트리거 범위

타임라인 트리거 연결에는 하나 이상의 타임라인을 연결할 수 있다. 모든, 해당 연결에 연관된 활성화 범위에 진입하면 관련 트리거 인스턴스를 활성화하고, 그 상태를 활성으로 설정한다. 어느 하나의, 해당 연결에 연관된 활성 범위에서 이탈하면 관련 트리거 인스턴스를 비활성화하고 그 상태를 비활성으로 설정한다. 따라서 실질적으로 트리거에 연결된 모든 타임라인 상태의 논리 OR를 형성한다. 예를 들어 요소가 수직 AND 수평 스크롤 영역의 교차 영역에 진입하는 경우이다.

참고: 기본적으로 활성 범위는 활성화 범위와 같다. 수동으로 지정하더라도 활성 범위는 항상 상위 집합으로서 활성화 범위를 포함한다. 예를 들어 이 두 범위를 사용하면 animation-trigger가 요소가 화면 중앙 근처로 스크롤되었을 때 애니메이션을 시작하게 할 수 있다 （뷰 진행 타임라인에서 비교적 작은 구간을 활성화 범위로 사용）. 그러면서 요소가 화면 밖으로 완전히 나갈 때까지 멈추지 않게 할 수 있다 （cover를 활성 범위로 사용）.

4. 이벤트 트리거

이벤트 트리거는 트리거의 한 종류로, 요소에서 특정 Event가 발생하면 활성화된다. 요소에서 event-trigger 단축 속성 또는 그 개별 속성으로 정의한다.

이벤트 트리거는 무상태 또는 상태 유지 방식으로 정의할 수 있다:

  • 무상태인 경우 하나의 진입 이벤트 집합이 있으며, 이 이벤트들이 트리거를 활성화한다.

  • 상태 유지 방식인 경우 두 이벤트 집합, 즉 진입 이벤트 집합과 별도의 이탈 이벤트 집합을 가진다.

이벤트 트리거는 연관된 Event 중 하나가 페이지에서 발생하면 활성화된다. 이벤트의 target은 트리거를 정의한 요소이다. 상태 유지 방식이라면 이진 트리거 상태가 연결되며, 초깃값은 "inactive"이다: "inactive"인 동안에는 정의 요소가 진입 이벤트를 받을 때만 활성화되어, 연관된 진입 동작을 수행하고 트리거 상태를 "active"로 바꾼다. "active"인 동안에는 이탈 이벤트를 받을 때만 비활성화되어, 연관된 이탈 동작을 수행하고 트리거 상태를 다시 "inactive"로 바꾼다.

무상태 이벤트 트리거의 트리거 인스턴스에는 정확히 하나의 동작을 지정해야 한다. 상태 유지 방식에는 하나 또는 두 개를 지정할 수 있다: 첫 번째는 진입 동작이고, 두 번째를 제공하면 이는 이탈 동작이다. 두 번째를 제공하지 않으면 이탈 동작은 아무것도 하지 않는 것이다.

참고: 상태 유지 방식과 무상태 이벤트 트리거는 하나의 동작만 지정하더라도 다르게 동작한다. 단일 동작의 상태 유지 이벤트 트리거는 사실상 "꺼진" 상태가 되어, 이탈 이벤트를 받을 때까지 첫 번째 이후의 모든 진입 이벤트를 무시한다. 반면 무상태 트리거는 각 진입 이벤트마다 반복해서 트리거된다.

요소는 여러 이벤트 트리거를 정의할 수 있으며, 같거나 서로 다른 Event를 사용할 수 있다. event-trigger 개별 속성 집합은 조정 목록 속성 그룹을 구성한다. event-trigger-name이 조정 목록 기준 속성이며, 조정된 값 목록의 각 항목이 하나의 이벤트 트리거의 속성을 정의한다.

이 문장을 가져온 제안에서는 요소가 이벤트의 대상인지에만 관심을 둔다고 규정했다. 버블링 및/또는 캡처링도 허용할 필요가 있을 것이다. 선택적으로 활성화/비활성화하도록 할 수도 있다.

5. 트리거 애니메이션

CSS 애니메이션은 기본적으로 요소에 적절한 animation 값을 설정하는 즉시 자동으로 실행된다. animation-trigger 속성은 애니메이션의 시작을 적절한 트리거가 발생할 때까지 지연할 수 있게 하며, 트리거로 일시 정지, 재시작 또는 초기화할 수도 있게 한다 （이를 트리거 애니메이션으로 만든다）.

5.1. animation-trigger 속성

animation-trigger 속성은 애니메이션이 트리거 애니메이션인지 지정하고, 그렇다면 어떤 트리거에 응답하는지와 응답 시 어떤 동작을 수행하는지도 지정한다. animation-trigger는 초기화 전용 하위 속성으로, animation 단축 속성에 속한다. 값은 다음과 같다:

none

해당 애니메이션은 트리거 애니메이션이 아니다.

[ <dashed-ident> <animation-action>+ ]+

해당 애니메이션은 트리거 애니메이션으로, 각 <dashed-ident>가 명명하는 트리거에 응답하며, 해당 <animation-action>가 지정하는 동작을 수행한다. （§ 2.3 트리거 이름 범위: trigger-scope 속성에서 <dashed-ident>를 트리거로 해석하는 방법을 설명한다.）

트리거가 허용하는 <animation-action>의 개수와 정확히 무엇이 이를 활성화하는지는 트리거의 종류에 따라 결정된다. （이벤트 트리거는 무상태/상태 유지 여부에 따라 하나 또는 선택적인 두 번째 동작을 허용한다. 타임라인 트리거는 하나와 선택적인 두 번째 동작을 허용한다.） 잘못된 개수의 동작을 지정하는 것 （너무 많거나 너무 적은 경우）은 구문상 유효하지만, 트리거가 효과를 내지 못하게 한다.

[Exposed=Window]
interface AnimationTrigger {
  constructor(optional AnimationTriggerOptions options = {});
  attribute AnimationTimeline timeline;
  attribute AnimationTriggerBehavior behavior;
  attribute any activationRangeStart;
  attribute any activationRangeEnd;
  attribute any activeRangeStart;
  attribute any activeRangeEnd;
};

dictionary AnimationTriggerOptions {
  AnimationTimeline? timeline;
  AnimationTriggerBehavior? behavior = "once";
  (TimelineRangeOffset or CSSNumericValue or CSSKeywordValue or DOMString) activationRangeStart = "normal";
  (TimelineRangeOffset or CSSNumericValue or CSSKeywordValue or DOMString) activationRangeEnd = "normal";
  (TimelineRangeOffset or CSSNumericValue or CSSKeywordValue or DOMString) activeRangeStart = "auto";
  (TimelineRangeOffset or CSSNumericValue or CSSKeywordValue or DOMString) activeRangeEnd = "auto";
};
