요약

이 명세는 캐스케이딩 스타일 시트 레벨 2를 정의합니다. CSS는 작성자와 사용자가 구조화된 문서(예: HTML 문서 및 XML 애플리케이션)에 스타일(예: 글꼴 및 간격)을 추가할 수 있도록 하는 스타일 시트 언어입니다. 문서의 표현 스타일과 내용을 분리함으로써 CSS는 웹 작성 및 사이트 유지 관리를 단순화합니다.

CSS 2.2는 CSS 레벨 2의 두 번째 개정본 [CSS2]입니다. 이는 CSS 2.1(레벨 2의 첫 번째 개정본)의 몇 가지 오류를 수정했습니다. 이는 최신 CSS 버전이 아닙니다. CSS 전체를 구성하는 명세에 대한 개요는 "CSS Snapshot" [CSS]를 참고하십시오.

CSS 레벨 2는 미디어별 스타일 시트를 지원하여 작성자가 시각 브라우저, 청각 장치, 프린터, 점자 장치, 휴대용 장치 등 다양한 환경에 맞게 문서의 표현을 조정할 수 있도록 합니다. 또한 콘텐츠 배치, 표 레이아웃, 국제화 기능 및 사용자 인터페이스와 관련된 일부 속성을 지원합니다.

이 문서의 상태

이 섹션은 이 문서가 발행된 시점에서의 상태를 설명합니다. 다른 문서가 이 문서를 대체할 수 있습니다. 현재 W3C 발행물 목록과 이 기술 보고서의 최신 개정본은 W3C 기술 보고서 인덱스(http://www.w3.org/TR/)에서 확인할 수 있습니다.

첫 번째 공공 작업 초안으로 발행되었다고 해서 W3C 회원의 지지를 의미하지는 않습니다. 이 문서는 초안이며, 언제든지 업데이트, 교체 또는 폐기될 수 있습니다. 진행 중인 작업으로 이 문서를 인용하는 것은 적절하지 않습니다.

이 문서는 CSS 작업 그룹(스타일 활동의 일부)에 의해 작성되었습니다.

공개 메일링 리스트 www-style@w3.org(지침 참조)가 이 명세에 대한 논의에 선호됩니다. 이메일을 보낼 때 제목에 "CSS22"라는 텍스트를 포함하십시오. 예를 들어 “[CSS22] …코멘트 요약…”처럼 작성하십시오.

이 문서는 2004년 2월 5일 W3C 특허 정책에 따라 운영되는 그룹에 의해 작성되었습니다. W3C는 그룹의 결과물과 관련하여 공개된 특허 공개 목록을 유지합니다. 해당 페이지에는 특허를 공개하는 방법도 포함되어 있습니다. 개인이 필수적인 클레임을 포함하는 것으로 믿는 특허에 대한 실제 지식이 있는 경우 W3C 특허 정책 6항에 따라 정보를 공개해야 합니다.

이 문서는 2015년 9월 1일 W3C 프로세스 문서에 의해 관리됩니다.

이전 권고안 이후의 모든 변경 사항은 부록 C.에 나열되어 있습니다.
