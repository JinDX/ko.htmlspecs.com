B.1 표준 참조

[COLORIMETRY]

"정보 기술 - 유니버설 다중 옥텟 인코딩 문자 집합(UCS) - 1부: 아키텍처 및 기본 다국어 평면", ISO/IEC 10646-1:2003. 유용한 BMP 및 평면 1 문서는 각 숫자 범위에 어떤 스크립트가 위치하는지를 보여줍니다.
[PNG]
"Portable Network Graphics (PNG) Specification (두 번째 판)", David Duce, 편집, 2003년 11월 10일.
http://www.w3.org/TR/2003/REC-PNG-20031110/에서 제공.

"Uniform Resource Identifier (URI): Generic Syntax," T. Berners-Lee, R. Fielding, L. Masinter, 2005년 1월.
http://www.ietf.org/rfc/rfc3986에서 제공.
[RFC2045]
"Multipurpose Internet Mail Extensions (MIME) Part One: Format of Internet Message Bodies", N. Freed and N. Borenstein, 1996년 11월.

"HTTP Version 1.1", R. Fielding, J. Gettys, J. Mogul, et al., 1999년 6월.

[RFC2119]
"Key words for use in RFCs to Indicate Requirement Levels", S. Bradner, 1997년 3월.
http://www.ietf.org/rfc/rfc2119.txt에서 제공.

http://www.ietf.org/rfc/rfc2318.txt에서 제공.
[SRGB]

https://domino.iec.ch/publication/6169에서 제공.
[UAAG10]
"User Agent Accessibility Guidelines 1.0." Ian Jacobs, Jon Gunderson, Eric Hansen (편집자). 2002년 12월 17일.
http://www.w3.org/TR/2002/REC-UAAG10-20021217에서 제공.

http://www.unicode.org/reports/tr9/에서 제공.
[UNICODE]
"The Unicode Standard", 버전 8.0.0, Unicode 컨소시엄. (캘리포니아주 마운틴뷰: Unicode 컨소시엄, 2015. ISBN 978-1-936213-10-8). 새로운 버전이 출판될 때마다 업데이트됩니다. (최신 버전 및 표준과 Unicode 문자 데이터베이스의 버전에 대한 추가 정보는 http://www.unicode.org/unicode/standard/versions/에서 확인 가능).
http://www.unicode.org/versions/Unicode8.0.0/에서 제공.
