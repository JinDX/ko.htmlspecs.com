1. 소개

이 절은 규범적이지 않습니다.

이 명세서는 점, 사각형, 사변형 및 3x2와 4x4 차원의 변환 행렬을 표현하기 위한 여러 기하 인터페이스를 설명합니다.

SVG 인터페이스 SVGPoint, SVGRect 및 SVGMatrix는 여기서 정의된 인터페이스들을 별칭으로 제공하여 SVG, Canvas 2D Context 및 CSS Transforms에서 공통으로 사용됩니다. [SVG11] [HTML] [CSS3-TRANSFORMS]

2. DOMPoint 인터페이스

2D 또는 3D 점은 다음 WebIDL 인터페이스들로 표현될 수 있습니다:

[Constructor(optional unrestricted double x = 0, optional unrestricted double y = 0,
             optional unrestricted double z = 0, optional unrestricted double w = 1),
 Exposed=(Window,Worker),
 Serializable]
interface DOMPointReadOnly {
    [NewObject] static DOMPointReadOnly fromPoint(optional DOMPointInit other);

    readonly attribute unrestricted double x;
    readonly attribute unrestricted double y;
    readonly attribute unrestricted double z;
    readonly attribute unrestricted double w;

    DOMPoint matrixTransform(optional DOMMatrixInit matrix);

    [Default] object toJSON();
};

[Constructor(optional unrestricted double x = 0, optional unrestricted double y = 0,
             optional unrestricted double z = 0, optional unrestricted double w = 1),
 Exposed=(Window,Worker),
 Serializable,
 LegacyWindowAlias=SVGPoint]
interface DOMPoint : DOMPointReadOnly {
    [NewObject] static DOMPoint fromPoint(optional DOMPointInit other);

    inherit attribute unrestricted double x;
    inherit attribute unrestricted double y;
    inherit attribute unrestricted double z;
    inherit attribute unrestricted double w;
};

dictionary DOMPointInit {
    unrestricted double x = 0;
    unrestricted double y = 0;
    unrestricted double z = 0;
    unrestricted double w = 1;
};

다음 알고리즘들은 DOMPointReadOnly 객체들이 내부 멤버 변수로 x 좌표, y 좌표, z 좌표 및 w 원근 변수를 가진다고 가정합니다. DOMPointReadOnly 및 이를 상속하는 인터페이스 DOMPoint는 이 변수들의 값을 접근하고 설정할 수 있어야 합니다.

속성이나 함수가 DOMPointReadOnly 객체를 반환하는 경우 내부 멤버 변수 값을 수정할 수 있습니다. 그러한 인터페이스는 산문으로 이 능력을 명시해야 합니다.

내부 멤버 변수는 어떠한 방식으로도 노출되어서는 안 됩니다.

DOMPointReadOnly(x, y, z, w) 및 DOMPoint(x, y, z, w) 생성자는 호출될 때 다음 단계를 실행해야 합니다:

  1. point를 적절한 새로운 DOMPointReadOnly 또는 DOMPoint 객체로 둡니다.

  2. point의 변수들인 x 좌표를 x로, y 좌표를 y로, z 좌표 를 z로, 그리고 w 원근을 w로 설정합니다.

  3. point를 반환합니다.

fromPoint(other) 정적 메서드는 DOMPointReadOnly 위에서 사전에서 DOMPointReadOnly 생성을 통해 other로부터 DOMPointReadOnly를 생성해야 합니다.

fromPoint(other) 정적 메서드는 DOMPoint에 대해 사전에서 DOMPoint 생성을 통해 other로부터 DOMPoint를 생성해야 합니다.

사전으로부터 DOMPointReadOnly를 생성하거나, 혹은 사전으로부터 DOMPoint를 생성하려면 다음 단계를 따르십시오:

  1. point를 적절한 새로운 DOMPointReadOnly 또는 DOMPoint 객체로 둡니다.

  2. point의 변수들인 x 좌표를 other의 사전 멤버 x로, y 좌표를 other의 사전 멤버 y로, z 좌표를 other의 사전 멤버 z로, 그리고 w 원근을 other의 사전 멤버 w로 설정합니다.

  3. point를 반환합니다.

x 속성은 접근 시 x 좌표 값을 반환해야 합니다. DOMPoint 인터페이스의 경우, x 속성을 설정하면 x 좌표를 새 값으로 설정해야 합니다.

y 속성은 접근 시 y 좌표 값을 반환해야 합니다. DOMPoint 인터페이스의 경우, y 속성을 설정하면 y 좌표를 새 값으로 설정해야 합니다.

z 속성은 접근 시 z 좌표 값을 반환해야 합니다. DOMPoint 인터페이스의 경우, z 속성을 설정하면 z 좌표를 새 값으로 설정해야 합니다.

w 속성은 접근 시 w 원근 값을 반환해야 합니다. DOMPoint 인터페이스의 경우, w 속성을 설정하면 w 원근을 새 값으로 설정해야 합니다.

matrixTransform(matrix) 메서드는 호출될 때 다음 단계를 실행해야 합니다:

  1. matrixObject를 사전으로부터 DOMMatrix 생성을 통해 얻은 matrix의 결과로 둡니다.

  2. 현재 점과 matrixObject를 주어 행렬로 점을 변환을 호출한 결과를 반환합니다. 현재 점은 수정되지 않습니다.

이 예제에서 matrixTransform() 메서드는 DOMPoint 인스턴스에 대해 DOMMatrix 인스턴스를 인수로 하여 호출됩니다. 
var point = new DOMPoint(5, 4);
var matrix = new DOMMatrix([2, 0, 0, 2, 10, 10]);
var transformedPoint = point.matrixTransform(matrix);

point 변수는 x 좌표가 5로, y 좌표가 4로 초기화된 새로운 DOMPoint 객체로 설정됩니다. 이 새로운 DOMPoint는 matrix에 의해 스케일되고 평행이동됩니다. 결과인 transformedPoint는 x 좌표가 20이고 y 좌표가 18입니다.

2.1. 행렬로 점 변환하기

주어진 point와 matrix에 대해 행렬로 점을 변환하려면 다음을 수행합니다:

  1. x를 point의 x 좌표로 둡니다.

  2. y를 point의 y 좌표로 둡니다.

  3. z를 point의 z 좌표로 둡니다.

  4. w를 point의 w 원근로 둡니다.

  5. pointVector를 요소들이 각각 x, y, z, 및 w인 새로운 열 벡터로 둡니다.

    x y z w

  6. pointVector를 matrix로 후(행)곱합니다.

  7. transformedPoint를 새로운 DOMPoint 객체로 둡니다.

  8. transformedPoint의 x 좌표를 pointVector의 첫 번째 요소로 설정합니다.

  9. transformedPoint의 y 좌표를 pointVector의 두 번째 요소로 설정합니다.

  10. transformedPoint의 z 좌표를 pointVector의 세 번째 요소로 설정합니다.

  11. transformedPoint의 w 원근을 pointVector의 네 번째 요소로 설정합니다.

  12. transformedPoint를 반환합니다.

참고: 만약 matrix의 is 2D가 참이고, point의 z 좌표가 0 또는 -0이며, point의 w 원근가 1이라면, 이는 2D 변환입니다. 그렇지 않으면 3D 변환입니다.

3. DOMRect 인터페이스

다음 DOMRectReadOnly 인터페이스를 구현하는 객체들은 사각형을 나타냅니다.

사각형은 다음과 같은 속성을 가집니다:

원점

사각형의 너비가 음수가 아닌 경우, 사각형의 수평 원점은 왼쪽 가장자리입니다. 그렇지 않으면 오른쪽 가장자리입니다. 마찬가지로, 사각형의 높이가 음수가 아닌 경우, 사각형의 수직 원점은 위쪽 가장자리입니다. 그렇지 않으면 아래쪽 가장자리입니다.

x 좌표

뷰포트의 왼쪽 가장자리와 사각형의 원점 사이의 수평 거리입니다.

y 좌표

뷰포트의 위쪽 가장자리와 사각형의 원점 사이의 수직 거리입니다.

너비

사각형의 너비입니다. 음수일 수 있습니다.

높이

사각형의 높이입니다. 음수일 수 있습니다.

[Constructor(optional unrestricted double x = 0, optional unrestricted double y = 0,
             optional unrestricted double width = 0, optional unrestricted double height = 0),
 Exposed=(Window,Worker),
 Serializable]
interface DOMRectReadOnly {
    [NewObject] static DOMRectReadOnly fromRect(optional DOMRectInit other);

    readonly attribute unrestricted double x;
    readonly attribute unrestricted double y;
    readonly attribute unrestricted double width;
    readonly attribute unrestricted double height;
    readonly attribute unrestricted double top;
    readonly attribute unrestricted double right;
    readonly attribute unrestricted double bottom;
    readonly attribute unrestricted double left;

    [Default] object toJSON();
};

[Constructor(optional unrestricted double x = 0, optional unrestricted double y = 0,
             optional unrestricted double width = 0, optional unrestricted double height = 0),
 Exposed=(Window,Worker),
 Serializable,
 LegacyWindowAlias=SVGRect]
interface DOMRect : DOMRectReadOnly {
    [NewObject] static DOMRect fromRect(optional DOMRectInit other);

    inherit attribute unrestricted double x;
    inherit attribute unrestricted double y;
    inherit attribute unrestricted double width;
    inherit attribute unrestricted double height;
};

dictionary DOMRectInit {
    unrestricted double x = 0;
    unrestricted double y = 0;
    unrestricted double width = 0;
    unrestricted double height = 0;
};

다음 알고리즘들은 DOMRectReadOnly 객체들이 내부 멤버 변수로 x 좌표, y 좌표, 너비 및 높이 변수를 갖는다고 가정합니다. DOMRectReadOnly 및 이를 상속하는 인터페이스 DOMRect는 이 변수들의 값을 접근하고 설정할 수 있어야 합니다.

속성이나 함수가 DOMRectReadOnly 객체를 반환하는 경우 내부 멤버 변수 값을 수정할 수 있습니다. 그러한 인터페이스는 산문으로 이 능력을 명시해야 합니다.

내부 멤버 변수는 어떠한 방식으로도 노출되어서는 안 됩니다.

DOMRectReadOnly(x, y, width, height) 및 DOMRect(x, y, width, height) 생성자는 호출될 때 다음 단계를 실행해야 합니다:

  1. rect를 적절한 새로운 DOMRectReadOnly 또는 DOMRect 객체로 둡니다.

  2. rect의 내부 변수들인 x 좌표를 x로, y 좌표를 y로, 너비를 width로 그리고 높이를 height로 설정합니다.

  3. rect를 반환합니다.

fromRect(other) 정적 메서드는 DOMRectReadOnly 에서 사전으로부터 DOMRectReadOnly 생성을 통해 other로부터 생성해야 합니다.

fromRect(other) 정적 메서드는 DOMRect 에서 사전으로부터 DOMRect 생성을 통해 other로부터 생성해야 합니다.

사전으로부터 DOMRectReadOnly를 생성하거나, 혹은 사전으로부터 DOMRect를 생성하려면 다음 단계를 따르십시오:

  1. rect를 적절한 새로운 DOMRectReadOnly 또는 DOMRect로 둡니다.

  2. rect의 내부 변수들인 x 좌표를 other의 사전 멤버 x로, y 좌표를 other의 사전 멤버 y로, 너비를 other의 사전 멤버 width로 그리고 높이를 other의 사전 멤버 height로 설정합니다.

  3. rect를 반환합니다.

x 속성은 접근 시 x 좌표 값을 반환해야 합니다. DOMRect 인터페이스의 경우, x 속성을 설정하면 x 좌표를 새 값으로 설정해야 합니다.

y 속성은 접근 시 y 좌표 값을 반환해야 합니다. DOMRect 인터페이스의 경우, y 속성을 설정하면 y 좌표를 새 값으로 설정해야 합니다.

width 속성은 접근 시 너비 값을 반환해야 합니다. DOMRect 인터페이스의 경우, width 속성을 설정하면 너비를 새 값으로 설정해야 합니다.

height 속성은 접근 시 높이 값을 반환해야 합니다. DOMRect 인터페이스의 경우, height 속성을 설정하면 높이를 새 값으로 설정해야 합니다.

top 속성은 접근 시 min(y 좌표, y 좌표 + 높이)을 반환해야 합니다.

right 속성은 접근 시 max(x 좌표, x 좌표 + 너비)을 반환해야 합니다.

bottom 속성은 접근 시 max(y 좌표, y 좌표 + 높이)을 반환해야 합니다.

left 속성은 접근 시 min(x 좌표, x 좌표 + 너비)을 반환해야 합니다.

4. DOMRectList 인터페이스

interface DOMRectList {
    readonly attribute unsigned long length;
    getter DOMRect? item(unsigned long index);
};

length 속성은 객체와 연관된 DOMRect 객체들의 총 개수를 반환해야 합니다.

item(index) 메서드는 호출될 때, index가 객체와 연관된 DOMRect 객체의 수보다 크거나 같으면 null을 반환해야 합니다. 그렇지 않으면 index에 해당하는 DOMRect 객체를 반환해야 합니다. 인덱스는 0부터 시작합니다.

DOMRectList 는 레거시 웹 콘텐츠와의 호환성을 위해서만 존재합니다. 새로운 API를 설계할 때는 DOMRectList를 사용하지 마십시오. 대신 sequence<DOMRect>를 사용하십시오. [WEBIDL]

내부 멤버 변수는 어떠한 방식으로도 노출되어서는 안 됩니다.

DOMQuad(p1, p2, p3, p4) 생성자는 호출될 때 다음 단계를 실행해야 합니다:

  1. point1를 p1의 동명 딕셔너리 멤버 값들로 속성이 설정된 새로운 DOMPoint 객체로 둡니다.

  2. point2를 p2의 동명 딕셔너리 멤버 값들로 속성이 설정된 새로운 DOMPoint 객체로 둡니다.

  3. point3를 p3의 동명 딕셔너리 멤버 값들로 속성이 설정된 새로운 DOMPoint 객체로 둡니다.

  4. point4를 p4의 동명 딕셔너리 멤버 값들로 속성이 설정된 새로운 DOMPoint 객체로 둡니다.

  5. 다음과 같이 설정된 새로운 DOMQuad를 반환합니다: point 1은 point1로, point 2는 point2로, point 3은 point3로, 및 point 4는 point4로 설정됩니다.

참고: DOMPoint/DOMPointReadOnly 타입의 인수를 전달할 수도 있습니다. 전달된 인수들은 WebIDL 규칙을 따라 내부적으로 올바른 객체 타입으로 변환됩니다. [WEBIDL]

fromRect(other) 정적 메서드는 DOMQuad 에서 DOMRectInit 딕셔너리로부터 DOMQuad 생성을 통해 other로부터 생성해야 합니다.

DOMRectInit 딕셔너리로부터 DOMQuad를 생성하려면 다음 단계를 따르십시오:

  1. x, y, width 및 height를 각각 other의 딕셔너리 멤버 x, y, width 및 height의 값으로 둡니다.

  2. point1를 다음과 같이 속성이 설정된 새로운 DOMPoint 객체로 둡니다: x 좌표는 x, y 좌표는 y, z 좌표는 0, 그리고 w 원근는 1로 설정됩니다.

  3. point2를 다음과 같이 속성이 설정된 새로운 DOMPoint 객체로 둡니다: x 좌표는 x + width, y 좌표는 y, z 좌표는 0, 그리고 w 원근는 1로 설정됩니다.

  4. point3를 다음과 같이 속성이 설정된 새로운 DOMPoint 객체로 둡니다: x 좌표는 x + width, y 좌표는 y + height, z 좌표는 0, 그리고 w 원근는 1로 설정됩니다.

  5. point4를 다음과 같이 속성이 설정된 새로운 DOMPoint 객체로 둡니다: x 좌표는 x, y 좌표는 y + height, z 좌표는 0, 그리고 w 원근는 1로 설정됩니다.

  6. 다음과 같이 설정된 새로운 DOMQuad를 반환합니다: point 1은 point1로, point 2는 point2로, point 3은 point3로, 및 point 4는 point4로 설정됩니다.

fromQuad(other) 정적 메서드는 DOMQuad 에서 DOMQuadInit 딕셔너리로부터 DOMQuad 생성을 통해 other로부터 생성해야 합니다.

다음은 DOMQuadInit 딕셔너리로부터 DOMQuad를 생성하는 단계입니다:

  1. point1를, 존재하는 경우 other의 딕셔너리 멤버 p1에 대해 사전으로부터 DOMPoint 생성을 호출한 결과로 둡니다.

  2. point2를, 존재하는 경우 other의 딕셔너리 멤버 p2에 대해 사전으로부터 DOMPoint 생성을 호출한 결과로 둡니다.

  3. point3를, 존재하는 경우 other의 딕셔너리 멤버 p3에 대해 사전으로부터 DOMPoint 생성을 호출한 결과로 둡니다.

  4. point4를, 존재하는 경우 other의 딕셔너리 멤버 p4에 대해 사전으로부터 DOMPoint 생성을 호출한 결과로 둡니다.

  5. 다음과 같이 설정된 새로운 DOMQuad를 반환합니다: point 1은 point1로, point 2는 point2로, point 3은 point3로, 및 point 4는 point4로 설정됩니다.

p1 속성은 point 1을 반환해야 합니다.

p2 속성은 point 2를 반환해야 합니다.

p3 속성은 point 3를 반환해야 합니다.

p4 속성은 point 4를 반환해야 합니다.

getBounds() 메서드는 호출될 때 다음 알고리즘을 실행해야 합니다:

  1. bounds를 DOMRect 객체로 둡니다.

  2. left를 point 1의 x 좌표, point 2의 x 좌표, point 3의 x 좌표 및 point 4의 x 좌표 중 최소값으로 둡니다.

  3. top를 point 1의 y 좌표, point 2의 y 좌표, point 3의 y 좌표 및 point 4의 y 좌표 중 최소값으로 둡니다.

  4. right를 point 1의 x 좌표, point 2의 x 좌표, point 3의 x 좌표 및 point 4의 x 좌표 중 최대값으로 둡니다.

  5. bottom를 point 1의 y 좌표, point 2의 y 좌표, point 3의 y 좌표 및 point 4의 y 좌표 중 최대값으로 둡니다.

  6. bounds의 x 좌표를 left로, y 좌표를 top로, 너비를 right - left로, 그리고 높이를 bottom - top으로 설정합니다.

  7. bounds를 반환합니다.

이 예제에서는 DOMQuad 생성자가 DOMPoint 타입 및 DOMPointInit 타입의 인수들과 함께 호출됩니다. 두 인수 모두 허용되며 사용될 수 있습니다. 
var point = new DOMPoint(2, 0);
var quad1 = new DOMQuad(point, {x: 12, y: 0}, {x: 12, y: 10}, {x: 2, y: 10});

위에서 생성된 DOMQuad quad1의 속성 값들은 다음 DOMQuad quad2의 속성 값들과도 동등합니다: 

var rect = new DOMRect(2, 0, 10, 10);
var quad2 = DOMQuad.fromRect(rect);
다음은 불규칙한 사변형의 예입니다: 
new DOMQuad({x: 40, y: 25}, {x: 180, y: 8}, {x: 210, y: 150}, {x: 10, y: 180});

6.1. DOMMatrix2DInit 및 DOMMatrixInit 딕셔너리

validate and fixup (2D)를 DOMMatrix2DInit 또는 DOMMatrixInit 딕셔너리 dict에 대해 수행하려면 다음 단계를 실행하십시오:

  1. 만약 dict에 대해 다음 조건들 중 적어도 하나가 참이면, TypeError 예외를 던지고 이 단계들을 중단합니다.

    • a 와 m11 이 모두 존재하고 SameValueZero(a, m11) 가 false 인 경우.

    • b 와 m12 이 모두 존재하고 SameValueZero(b, m12) 가 false 인 경우.

    • c 와 m21 이 모두 존재하고 SameValueZero(c, m21) 가 false 인 경우.

    • d 와 m22 이 모두 존재하고 SameValueZero(d, m22) 가 false 인 경우.

    • e 와 m41 이 모두 존재하고 SameValueZero(e, m41) 가 false 인 경우.

    • f 와 m42 이 모두 존재하고 SameValueZero(f, m42) 가 false 인 경우.

  2. 만약 m11 이 존재하지 않으면, 이를 멤버 a 의 값으로 설정하거나, a 도 존재하지 않으면 값 1로 설정합니다.

  3. 만약 m12 이 존재하지 않으면, 이를 멤버 b 의 값으로 설정하거나, b 도 존재하지 않으면 값 0으로 설정합니다.

  4. 만약 m21 이 존재하지 않으면, 이를 멤버 c 의 값으로 설정하거나, c 도 존재하지 않으면 값 0으로 설정합니다.

  5. 만약 m22 이 존재하지 않으면, 이를 멤버 d 의 값으로 설정하거나, d 도 존재하지 않으면 값 1으로 설정합니다.

  6. 만약 m41 이 존재하지 않으면, 이를 멤버 e 의 값으로 설정하거나, e 도 존재하지 않으면 값 0으로 설정합니다.

  7. 만약 m42 이 존재하지 않으면, 이를 멤버 f 의 값으로 설정하거나, f 도 존재하지 않으면 값 0으로 설정합니다.

참고: SameValueZero 비교 알고리즘은 두 개의 NaN 값에 대해 true를 반환하며, 0과 -0에 대해서도 true를 반환합니다. [ECMA-262]

validate and fixup를 DOMMatrixInit 딕셔너리 dict에 대해 수행하려면, 다음 단계를 실행하십시오:

  1. Validate and fixup (2D)를 dict에 대해 실행합니다.

  2. 만약 is2D 가 true 이고: m13, m14, m23, m24, m31, m32, m34, m43 중 적어도 하나가 0 또는 -0 이 아닌 값으로 존재하거나, m33, m44 중 적어도 하나가 1 이 아닌 값으로 존재하면, TypeError 예외를 던지고 이 단계들을 중단합니다.

  3. 만약 is2D 가 존재하지 않고, 위에서 열거한 m13, m14, m23, m24, m31, m32, m34, m43 중 적어도 하나가 0 또는 -0 이 아닌 값으로 존재하거나, m33 또는 m44 중 적어도 하나가 1 이 아닌 값으로 존재하면, is2D를 false로 설정합니다.

  4. 만약 is2D 가 여전히 존재하지 않으면, 이를 true로 설정합니다.

6.2. 문자열을 추상 행렬로 파싱하기

문자열 transformList가 주어졌을 때, 문자열을 추상 행렬로 파싱한다는 다음 단계를 실행함을 의미합니다. 결과로 4x4 추상 행렬과 불리언 2dTransform을 반환하거나 실패를 반환합니다.

  1. 만약 transformList가 빈 문자열이면, 이를 문자열 "matrix(1, 0, 0, 1, 0, 0)"으로 설정합니다.

  2. 파싱을 사용해 문법에 따라 transformList를 parsedValue로 파싱합니다. CSS transform 속성의 문법을 사용합니다. 결과는 <transform-list>, 키워드 none, 또는 실패가 됩니다. 만약 parsedValue가 실패이거나, 어떤 <transform-function>이 <length> 값을 가지며 절대 길이 단위(absolute length)가 없거나, none 이외의 키워드가 사용되면 실패를 반환합니다. [CSS3-SYNTAX] [CSS3-TRANSFORMS]

    2dTransform을 false로 설정합니다.

    그렇지 않으면

    2dTransform을 true로 설정합니다.

  5. 모든 <transform-function>들을 "변환 함수의 수학적 설명"에 따라 4x4 추상 행렬로 변환합니다. [CSS3-TRANSFORMS]

  2. invertSelf() 변환을 result에 대해 수행한다.

  3. result를 반환한다.

현재 행렬은 수정되지 않는다.

다음 메서드들도 현재 행렬을 수정하지 않는다.

transformPoint(point)

toFloat32Array()

현재 행렬의 16개 요소 m11 부터 m44 까지를 열 우선(column-major) 순서로 직렬화하여 Float32Array로 반환한다.

6.6. 가변 변환 메서드

다음 메서드들은 현재 행렬을 수정하므로, 각각의 메서드는 호출된 그 행렬을 반환합니다. 주요 이점은 콘텐츠 작성자가 메서드 호출을 체인으로 연결할 수 있다는 점입니다.

다음 코드 예제: 
var matrix = new DOMMatrix();
matrix.translateSelf(20, 20);
matrix.scaleSelf(2);
matrix.translateSelf(-20, -20);

는 다음과 동등합니다:

var matrix = new DOMMatrix();
matrix.translateSelf(20, 20).scaleSelf(2).translateSelf(-20, -20);

Note: 체인된 메서드 호출을 사용하는 저자들은 중간 DOMMatrix 객체의 생성으로 인해 불필요한 메모리 할당이 발생하지 않도록 가변 변환 메서드를 사용할 것을 권장합니다.

multiplySelf(other)

  1. otherObject를 딕셔너리 other로부터 DOMMatrix 생성의 결과로 설정합니다.

  2. otherObject 행렬을 현재 행렬에 post-multiply 합니다.

  3. 만약 is 2D가 otherObject에서는 false라면, 현재 행렬의 is 2D를 false로 설정합니다.

  4. 현재 행렬을 반환합니다.

preMultiplySelf(other)

  1. otherObject를 딕셔너리 other로부터 DOMMatrix 생성의 결과로 설정합니다.

  2. otherObject 행렬을 현재 행렬에 pre-multiply 합니다.

  3. 만약 is 2D가 otherObject에서 false이면, 현재 행렬의 is 2D를 false로 설정합니다.

  4. 현재 행렬을 반환합니다.

translateSelf(tx, ty, tz)

  1. Post-multiply 변환을 현재 행렬에 적용합니다. 3D 변환 행렬은 CSS Transforms에 서술되어 있습니다. [CSS3-TRANSFORMS]

  2. 만약 tz가 지정되어 있고 0 또는 -0이 아니면, 현재 행렬의 is 2D를 false로 설정합니다.

  3. 현재 행렬을 반환합니다.

scaleSelf(scaleX, scaleY, scaleZ, originX, originY, originZ)

  1. 현재 행렬에 대해 translateSelf()을 originX, originY, originZ 인수로 수행합니다.

  2. 만약 scaleY가 없으면 scaleY를 scaleX 값으로 설정합니다.

  3. Post-multiply 비균등 스케일 변환을 현재 행렬에 적용합니다. 3D 스케일 행렬은 CSS Transforms에 서술되어 있으며 sx = scaleX, sy = scaleY, sz = scaleZ입니다. [CSS3-TRANSFORMS]

  4. originX, originY, originZ의 부호를 반전합니다.

  5. 현재 행렬에 대해 translateSelf()을 originX, originY, originZ 인수로 수행합니다.

  6. 만약 scaleZ가 1이 아니거나 originZ가 0 또는 -0이 아니면, 현재 행렬의 is 2D를 false로 설정합니다.

  7. 현재 행렬을 반환합니다.

scale3dSelf(scale, originX, originY, originZ)

  1. 현재 행렬에 대해 translateSelf()을 originX, originY, originZ 인수로 적용합니다.

  2. Post-multiply 단일 3D 균일 스케일 변환을 현재 행렬에 적용합니다 (m11 = m22 = m33 = scale). 3D 스케일 행렬은 CSS Transforms에 서술되어 있으며 sx = sy = sz = scale입니다. [CSS3-TRANSFORMS]

  3. 현재 행렬에 대해 translateSelf()을 -originX, -originY, -originZ 인수로 적용합니다.

  4. 만약 scale이 1이 아니면, 현재 행렬의 is 2D를 false로 설정합니다.

  5. 현재 행렬을 반환합니다.

rotateSelf(rotX, rotY, rotZ)

  1. 만약 rotY와 rotZ가 둘 다 없으면, rotZ를 rotX 값으로 설정하고 rotX와 rotY를 0으로 설정합니다.

  2. 만약 rotY가 아직 없으면 rotY를 0으로 설정합니다.

  3. 만약 rotZ가 아직 없으면 rotZ를 0으로 설정합니다.

  4. 만약 rotX 또는 rotY가 0 또는 -0가 아니면, 현재 행렬의 is 2D를 false로 설정합니다.

  5. Post-multiply 회전 변환을 현재 행렬에 적용합니다. 이는 벡터 0,0,1을 중심으로 지정된 회전 rotZ도(degrees) 만큼 회전시키는 것입니다. 3D 회전 행렬은 CSS Transforms에 서술되어 있습니다. [CSS3-TRANSFORMS]

  6. Post-multiply 회전 변환을 현재 행렬에 적용합니다. 이는 벡터 0,1,0을 중심으로 지정된 회전 rotY도 만큼 회전시키는 것입니다. 3D 회전 행렬은 CSS Transforms에 서술되어 있습니다. [CSS3-TRANSFORMS]

  7. Post-multiply 회전 변환을 현재 행렬에 적용합니다. 이는 벡터 1,0,0을 중심으로 지정된 회전 rotX도 만큼 회전시키는 것입니다. 3D 회전 행렬은 CSS Transforms에 서술되어 있습니다. [CSS3-TRANSFORMS]

  8. 현재 행렬을 반환합니다.

rotateFromVectorSelf(x, y)

  1. Post-multiply 회전 변환을 현재 행렬에 적용합니다. 회전 각도는 벡터 (1,0)^T 와 (x,y)^T 사이의 시계 방향 각도로 결정됩니다. 만약 x와 y가 둘 다 0 또는 -0이면, 각도는 0으로 간주됩니다. 2D 회전 행렬은 CSS Transforms에 서술되어 있으며, 여기에 alpha는 (1,0)^T 와 (x,y)^T 사이의 각도(도)입니다. [CSS3-TRANSFORMS]

  2. 현재 행렬을 반환합니다.

rotateAxisAngleSelf(x, y, z, angle)

  1. Post-multiply 지정된 벡터 x, y, z를 중심으로 지정된 회전 각도 angle도 만큼 회전 변환을 현재 행렬에 적용합니다. 3D 회전 행렬은 CSS Transforms에 서술되어 있으며 alpha = angle (도)입니다. [CSS3-TRANSFORMS]

  2. 만약 x 또는 y가 0 또는 -0가 아니면, 현재 행렬의 is 2D를 false로 설정합니다.

  3. 현재 행렬을 반환합니다.

skewXSelf(sx)

  1. Post-multiply 지정된 각도 sx도 만큼 skewX 변환을 현재 행렬에 적용합니다. 2D skewX 행렬은 CSS Transforms에 서술되어 있으며 alpha = sx (도)입니다. [CSS3-TRANSFORMS]

  2. 현재 행렬을 반환합니다.

skewYSelf(sy)

  1. Post-multiply 지정된 각도 sy도 만큼 skewY 변환을 현재 행렬에 적용합니다. 2D skewY 행렬은 CSS Transforms에 서술되어 있으며 beta = sy (도)입니다. [CSS3-TRANSFORMS]

  2. 현재 행렬을 반환합니다.

invertSelf()

  1. 현재 행렬을 역행렬로 만듭니다.

  2. 만약 현재 행렬이 역행렬이 존재하지 않으면 모든 속성을 NaN으로 설정하고 is 2D를 false로 설정합니다.

  3. 현재 행렬을 반환합니다.

setMatrixValue(transformList)

  1. 문자열을 추상 행렬로 파싱을 실행하고 결과를 matrix와 2dTransform에 두십시오. 만약 결과가 실패이면 "SyntaxError" DOMException을 던집니다.

  2. is 2D를 2dTransform의 값으로 설정합니다.

  3. m11 element부터 m44 element까지를 matrix의 요소 값들로 열 우선(column-major) 순서로 설정합니다.

  4. 현재 행렬을 반환합니다.

8. 개인정보 및 보안 고려사항

The DOMMatrix and DOMMatrixReadOnly interfaces have entry-points to parsing a string with CSS syntax. Therefore the privacy and security considerations of the CSS Syntax specification applies. [CSS3-SYNTAX]

이는 잠재적으로 사용자 에이전트의 CSS 파서의 버그를 악용하는 데 사용될 수 있습니다.

이 명세에서 정의한 인터페이스들에 대한 다른 알려진 보안 또는 개인정보 영향은 없습니다. 그러나 이 명세에서 정의한 인터페이스를 사용하는 API를 가진 다른 명세들은 잠재적으로 보안 또는 개인정보 문제를 도입할 수 있습니다.

예를 들어, getBoundingClientRect() API(CSSOM View에 정의됨)는 DOMRect를 반환하며, 이는 특정 글꼴로 일부 텍스트를 포함하는 인라인 요소의 크기를 측정하는 데 사용될 수 있고, 사용자가 해당 글꼴을 설치했는지에 대한 정보를 노출할 수 있습니다. 많은 일반 글꼴을 테스트하는 데 사용되면 해당 정보는 개인 식별 가능 정보가 될 수 있습니다. [CSSOM-VIEW]

9. 역사적 사항

이 절은 규범적이지 않습니다.

이 명세의 인터페이스들은 다양한 명세들에 있었던 이전의 유사한 인터페이스들과 일부 사용자 에이전트에서 제공되던 독점 인터페이스들을 대체하도록 의도되었습니다. 이 절에서는 이러한 인터페이스들을 열거하려고 합니다.

9.1. CSSOM View

이전 CSSOM View 개정에서는 ClientRect 인터페이스를 정의했으며, 이는 DOMRect로 대체되었습니다. 이 명세를 준수하는 구현은 ClientRect를 지원하지 않습니다. [CSSOM-VIEW]

9.2. SVG

이전 SVG 개정에서는 SVGPoint, SVGRect, SVGMatrix 등을 정의했으며, 이들은 본 명세에서 각각 DOMPoint, DOMRect, DOMMatrix 의 별칭으로 정의되어 있습니다. [SVG11]

9.3. 비표준

일부 사용자 에이전트는 WebKitPoint 인터페이스를 지원했습니다. 이 명세를 준수하는 구현은 WebKitPoint를 지원하지 않습니다.

여러 사용자 에이전트는 널리 사용되는 WebKitCSSMatrix 인터페이스를 지원했으며, 이는 본 명세에서 DOMMatrix의 별칭으로 정의되어 있습니다.

일부 사용자 에이전트는 MSCSSMatrix 인터페이스를 지원했습니다. 이 명세를 준수하는 구현은 MSCSSMatrix를 지원하지 않습니다.

이 명세에 대한 적합성은 세 개의 적합성 클래스에 대해 정의됩니다:

style sheet
CSS 스타일 시트.
renderer
스타일 시트의 의미론을 해석하고 문서를 렌더링하는 UA.

스타일 시트는 본 모듈에서 정의된 문법을 사용하는 모든 문장이 일반 CSS 문법과 각 기능의 개별 문법에 따라 유효하면 이 명세에 적합합니다.

작성 도구는 일반 CSS 문법 및 본 모듈의 각 기능에 대한 개별 문법에 따라 구문적으로 올바른 스타일 시트를 작성하고, 본 모듈에 설명된 스타일 시트에 대한 모든 적합성 요구사항을 충족하면 적합합니다.

CSS의 책임 있는 구현 요구사항

다음 절들은 현재와 미래의 상호운용성을 촉진하는 방식으로 CSS를 책임 있게 구현하기 위한 여러 적합성 요구사항을 정의합니다.

부분적 구현

작성자가 전방 호환 파싱 규칙을 활용하여 대체 값을 지정할 수 있도록, CSS 렌더러는 지원 수준이 없는 at-rule, 속성, 속성 값, 키워드 및 기타 문법 구성들을 유효하지 않은 것으로 처리하고 (적절히 무시해야 합니다). 특히 사용자 에이전트는 지원되지 않는 속성 값들을 선택적으로 무시하고 단일 다중값 속성 선언에서 지원되는 값만을 존중해서는 안 됩니다: 어떤 값이라도 유효하지 않은 것으로 간주되면(지원되지 않는 값은 그러해야 한다), CSS는 전체 선언을 무시하도록 요구합니다.

불안정하고 독점적인 기능의 구현

향후 안정된 CSS 기능과의 충돌을 피하기 위해, CSSWG는 불안정 기능 및 독점 확장의 구현에 대해 최선의 관행을 따를 것을 권장합니다.

CR 종료 기준

이 명세가 제안 권고(Proposed Recommendation)로 진전되려면, 각 기능에 대해 적어도 두 개의 독립적이고 상호운용 가능한 구현이 있어야 합니다. 각 기능은 서로 다른 제품 세트에 의해 구현될 수 있으며, 모든 기능이 단일 제품에 의해 구현되어야 할 필요는 없습니다. 이 기준의 목적을 위해 다음 용어들을 정의합니다:

independent

interoperable

implementation
해당 명세를 구현하는 사용자 에이전트로서:
  1. 명세를 구현합니다.
  2. 일반 대중이 이용할 수 있습니다. 구현은 출시 제품 또는 기타 공개 버전(예: 베타, 프리뷰, "nightly build")일 수 있습니다. 비출시 제품 릴리스는 안정성을 증명하기 위해 최소 한 달 이상 기능을 구현해야 합니다.
